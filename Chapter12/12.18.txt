Why doesn’t shared_ptr have a release member?

shared_ptr does not have a release member because it doesn't need to worry about being the sole owner of the pointer the way unique_ptr does. Implied by the name shared_ptr can have many shared_ptr's pointing to the same resource whereas unique_ptr requires sole ownership and using release to relinquish that ownership so that another unique_ptr could gain ownership of that pointer is important. It is also impossible to safely implement release() when there are multiple pointers sharing the same resource, if a shared_ptrwere to release its raw pointer while other shared_ptrs still pointed to that resource, then this would lead to having a dangling pointer.
