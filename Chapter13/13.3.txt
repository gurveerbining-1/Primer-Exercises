What happens when we copy a StrBlob? What about StrBlobPtrs?

When we copy a StrBlob its copy constructor is called which takes in the reference to an object of the StrBlob class, since there is no explicitly defined copy constructor one is synthesized by the compiler and used instead. Since this copy constructor copies each member of the StrBlob, the shared_ptr for the newly created StrBlob object points to the same vector as the StrBlob object that was used to initalize this new one. For the StrBlobPtr class, there is also no explicitly defined copy constructor so the compiler synthesizes one and uses it. It then copies each member of the StrBlobPtr class into this newly created StrBlobPtr which includes the weak_ptr that points to a vector, both of these weak_ptrs refer to the same underlying vector.
