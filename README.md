# C++ Primer Exercises

My solutions to the exercises from **[C++ Primer (5th Edition)](https://www.amazon.ca/Primer-5th-Stanley-B-Lippman/dp/0321714113)** by Stanley B. Lippman, Josée Lajoie, and Barbara E. Moo.

The goal of this repository is to build a deeper understanding of modern C++ through consistent practice, with an emphasis on understanding the language rather than simply completing exercises.

## What I'm Learning

The exercises cover topics including:

* C++ fundamentals and syntax
* Variables, types, and expressions
* Functions
* Classes and object-oriented programming
* Copy control and object lifetime
* Dynamic memory
* Templates and generic programming
* The Standard Template Library (STL)
* Iterators and algorithms
* Containers
* Object-oriented design
* Advanced C++ features

## Repository Structure

Exercises are organized by chapter:

```text
cpp-primer/
├── Chapter1/
├── Chapter2/
├── Chapter3/
├── ...
└── Chapter19/
```

Each chapter contains my solutions to the corresponding exercises from the book.

## Building

The exercises are compiled using a C++ compiler with support for modern C++ standards.

Example:

```bash
g++ main.cpp -o main
./main
```

Some exercises may contain multiple source files and use a separate build configuration.

## Purpose

This repository is primarily a **learning log and reference** for my progression through C++.

Rather than treating the exercises as isolated problems, I'm using them to reinforce concepts that are important for systems and software development, particularly:

* Memory management
* Object lifetime
* RAII
* Copy and move semantics
* STL and generic programming
* Resource management
* C++ abstractions and their underlying costs

I'll continue adding solutions as I work through the book.
